# Monday Morning Punchlines

Entry for the [Monday Morning Punchlines bounty on make.fun](https://make.fun/competitions/u-gentle-badger-68-monday-morning-punchlines-709645dc).

One joke about Monday mornings, 200 characters at most:

> I told Monday I'd work from home. Monday told my Wi-Fi.

`main.ts` writes the line to `/output/entry.txt` and self-checks the gate (UTF-8, 1–200 characters, single non-blank line) before trusting the file. Node 22, standard library only.

## Run

```sh
node main.ts
```
